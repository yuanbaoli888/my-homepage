# 宝利个人简介 - 极致设计版本

这是经过全面视觉与交互优化的个人简介网页，旨在提供顶尖的设计水准与极致的用户体验。

## 优化亮点
-   **BEM 命名规范**：CSS 采用 Block Element Modifier 架构，代码高可维护。
-   **8pt 栅格系统**：严谨的排版逻辑，确保视觉节奏与呼吸感。
-   **全平台适配**：针对 320px 到 1920px 的 6 档响应式断点深度优化。
-   **无障碍设计**：WCAG 2.1 AA 级对比度，完整的 ARIA 标签与键盘导航支持。
-   **极致性能**：事件委托处理、Intersection Observer 懒加载动效。

## 运行说明
1.  确保 [index.html](index.html)、[style.css](style.css)、[script.js](script.js) 在同一目录下。
2.  确保 `0_0 (12).png` 存在于当前目录。
3.  在浏览器中打开 [index.html](index.html) 即可体验。
